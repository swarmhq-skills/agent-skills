# Guest room prep checklist

Ready for guests without the last-minute rush.

## Requirements

- Arrival and departure dates
- Number of guests
- Optional: dietary needs or preferences the user shares

## When to use

- A week before guests arrive

## Steps

1. Ask for dates and what the user already has ready.
2. List tasks by day: linens, space in the wardrobe, towels, spare key, wifi details.
3. Add a short note card with wifi and house basics for the user to review.
4. Mark what still needs buying and add it to a list.

## Rules

- Use only details the user gives about guests.
- Do not message guests without approval.
- Do not buy anything without approval.

## Output format

```
Guest prep (dates)
- Tasks by day
- To buy
- Note card draft
```
