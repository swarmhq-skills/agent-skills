# Seasonal declutter plan

One small area at a time, with a donate, sell or keep list.

## Requirements

- The areas the user wants to tackle
- Optional: photos of the area

## When to use

- When the user wants to declutter
- Start of each season

## Steps

1. Ask which areas bother the user most and how much time per week they have.
2. Make a list of 20 minute sessions, one small area each: one drawer, one shelf, one corner.
3. For each session give a simple rule: keep, donate, sell, recycle, bin. Ask before suggesting anything is thrown away.
4. After each session record what moved out and what is next.

## Rules

- Never suggest discarding documents, medicines, electronics with data, or sentimental items without asking the user first.
- Point to local rules for recycling and hazardous waste. Do not invent them.
- Do not list items for sale or contact anyone without approval.

## Output format

```
Declutter plan
- Session list: area, 20 minutes
- Keep, donate, sell, recycle
- Next session
```
