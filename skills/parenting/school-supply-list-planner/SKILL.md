# School supply list planner

Back-to-school shopping with a list that fits.

## Requirements

- The school's supply list the user provides
- What the family already has

## When to use

- Before the school year
- At the start of a term

## Steps

1. Read the list the school sent and split it into items and quantities.
2. Cross off what the family already has.
3. Group the rest by shop type and add a note for items that must be a specific kind.
4. Keep the list for next term.

## Rules

- Use only the school's own list.
- Do not buy anything without approval.
- Do not add school or child names to anything shared.

## Output format

```
Supply list
- Already have
- To buy by shop type
- Specific kinds required
```
