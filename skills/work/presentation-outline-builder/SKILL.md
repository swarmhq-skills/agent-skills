# Presentation outline builder

A clear outline before you open the slides.

## Requirements

- Topic, audience and time limit
- The user's notes or documents

## When to use

- Before building slides

## Steps

1. Ask who the audience is and what they should do afterwards.
2. State the one message of the talk in a sentence.
3. Draft one slide per point with a headline message and the evidence the user must supply.
4. Fit the number of slides to the time limit.

## Rules

- Use facts only from the user's sources. Mark missing evidence as "to add".
- Do not invent figures or quotes.
- Do not send the outline to anyone without approval.

## Output format

```
Outline (topic, time)
- Main message
- Slide: headline, evidence needed
- Gaps to fill
```
