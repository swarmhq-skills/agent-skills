# Interview prep sheet

A one-page sheet for the day of the interview.

## Requirements

- The job post
- The user's CV or notes

## When to use

- Before an interview

## Steps

1. Read the job post and list the main skills it asks for.
2. Match each skill to a real example from the user's own experience.
3. Write short answers for the user to practise, in the user's own words.
4. Add three questions for the user to ask and a checklist for the day.

## Rules

- Use only experience the user shares. Never invent achievements.
- Do not contact the employer without approval.
- Do not claim anything about the company that is not on its own site.

## Output format

```
Interview sheet (role)
- Skills asked for
- Example per skill
- Questions to ask
- Day-of checklist
```
