# Performance review prep

Walk into the review with your evidence.

## Requirements

- The user's notes and finished work
- Feedback the user received
- Optional: goals set at the last review

## When to use

- A few weeks before a review

## Steps

1. Gather the user's notes, project lists and positive feedback they provide.
2. Group them under the goals, or under themes if no goals exist.
3. Write each achievement as one line: what was done and what changed.
4. Suggest two questions the user can ask their manager and one area to develop.

## Rules

- Use only what the user provides.
- Do not invent results or numbers.
- Do not share the document with anyone without approval.

## Output format

```
Review prep
- Achievements by goal
- Feedback received
- Areas to develop
- Questions for the manager
```
